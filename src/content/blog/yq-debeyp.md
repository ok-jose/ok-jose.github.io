1.统一社会信用代码

> 参照标准：
>
> 《GB_32100-2015_法人和其他组织统一社会信用代码编码规则.》
>
> 按照编码规则:
>

> 统一代码为18位，统一代码由十八位的数字或大写英文字母（不适用I、O、Z、S、V）组成，由五个部分组成：
>

> 第一部分（第1位）为登记管理部门代码，9表示工商部门；(数字或大写英文字母)
>

> 第二部分（第2位）为机构类别代码;(数字或大写英文字母)
>

> 第三部分（第3-8位）为登记管理机关行政区划码；(数字)
>

> 第四部分（第9-17位）为全国组织机构代码；(数字或大写英文字母)
>

> 第五部分（第18位）为校验码(数字或大写英文字母)
>

```javascript
/([^_IOZSVa-z\W]{2}\d{6}[^_IOZSVa-z\W]{10}|^\d{15}$)/
// message: 必须为18位，且由数字和除(I、O、Z、S、V)之外的大写字母组成
```

3.身份证号

> 大陆身份证号
>

```javascript
/^[1-9]\d{5}[1-9]\d{7}[0-9]{3}[0-9Xx]/
// message: 身份证号必须为18位数字或前17位数字加上最后一位字母'X'或'x'
```

7.网址

> http/https/ftp/file
>

```javascript
/^(https?|ftp|file):\/\/([\w-]+\.)+[\w-]+(\/?[\w-.\/?%&#=]*)?/
// message: url的协议头需以"http/https/ftp/file"开始
```

8.银行卡号

> 银行卡号
>

```javascript
/^[1-9]\d{12,18}/
// message: 卡号的长度为13-19位，且第一位不为0
```

9.手机号

> 判断 从1[3456789] 开头，然后后面9位数字
>

```javascript
/^1[3456789]\d{9}/
// message: 手机号格式不正确
```

10. 邮箱

```javascript
/^([a-zA-Z0-9_-])+@([a-zA-Z0-9_-])+(.[a-zA-Z0-9_-]+)+/
// message: 邮箱格式不正确
```
